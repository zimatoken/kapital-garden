# 🌳 Kapital Garden

> Каждая отложенная копейка — семя твоего будущего.

**Kapital Garden** — не учёт трат. Не бюджет. Не финансовый советник.

Это **САД ТВОЕГО КАПИТАЛА**. Каждая отложенная копейка — семя. Каждая неделя — росток. Каждый месяц — дерево. Каждый год — лес.

Главный принцип: **откладывай 10% — и твой сад растёт.**

---

## 🚀 Живое приложение

🔗 **[zimatoken.github.io/kapital-garden](https://zimatoken.github.io/kapital-garden/)**

Работает офлайн. Устанавливается как PWA. Данные хранятся только у тебя (localStorage).

## ✨ Что умеет

### 🌳 Мой сад
- 8 октав роста дерева: 🌱 Семя → 🌿 Росток → 🌾 Стебель → 🌳 Молодое дерево → 🌸 Цветущее → 🍎 Плодоносящее → 🌲 Большое → 🏞 Лес
- 🔥 Стрик — огненный круг (не сгорает, только увядает)
- 📊 Пульс — сравнение с собой
- 📅 Сад года — 12 месяцев

### 💰 Бюджет
- Доходы и расходы
- 7 базовых категорий (Еда, Авто, Дом, Развлечения, Покупки, Здоровье, Дети)
- **Умный парсер** — «Заправил машину» → 🚗 Авто
- **Фильтры** — по типу, месяцу, категории, поиск
- **Паттерны** — средний чек, топ-категории, любимый день трат
- **Авто-10%** с каждого дохода → предложение отложить

### 🎯 Цели
- 5 типов: 🏡 Квартира / 🚗 Машина / 🌴 Отпуск / 🎓 Образование / 💎 Своя
- 7 стадий роста дерева цели
- **Сценарии ускорения** — «Что если +10% / +25% / +50% / +100%?»

### 📊 Аналитика
- График по месяцам (доход / расход / отложено)
- Круговая диаграмма «Куда уходят деньги»
- Факты без оценок: savings rate, рекордный месяц, динамика

### 🏆 Награды
- 9 достижений: 🌱 Первый росток → 🏞 Лес

### ⚙️ Ещё
- 🔁 Регулярные расходы (ЖКХ, подписки, ипотека)
- 📤 Экспорт JSON / 📊 Экспорт CSV
- 🎨 Темы: светлая / тёмная / системная
- 📘 Инструкция (кнопка `?` на каждом экране)

## 🧬 Философия (10 принципов)

1. **МОТИВАЦИЯ ВАЖНЕЕ КОНТРОЛЯ.** Ты видишь, как растёт.
2. **САД ВАЖНЕЕ ТАБЛИЦЫ.** Не столбцы цифр, а растущий сад.
3. **РОСТ ВАЖНЕЕ ЭКОНОМИИ.** Не «сократи траты», а «откладывай 10%».
4. **ПРОСТОТА ВАЖНЕЕ ФУНКЦИОНАЛЬНОСТИ.** 7 категорий, не 50.
5. **ПОСТОЯНСТВО ВАЖНЕЕ РЫВКА.** Лучше 100 ₽ в день, чем 10 000 ₽ раз в месяц.
6. **ДОЛГОСРОЧНОСТЬ ВАЖНЕЕ БЫСТРОГО РЕЗУЛЬТАТА.** Через 10 лет — могучее дерево.
7. **ПРИВАТНОСТЬ ВАЖНЕЕ АНАЛИТИКИ.** localStorage. Данные только у тебя.
8. **РУЛЬ У ТЕБЯ.** Приложение показывает. Ты решаешь.
9. **НЕТ ОЦЕНОК.** Не «хорошо/плохо». Только факты.
10. **ТИШИНА ВАЖНЕЕ ШУМА.** Никаких «ТЫ ПОТРАТИЛ СЛИШКОМ МНОГО».

## 🛠️ Технологии

- **React 18** + **TypeScript** + **Vite**
- **PWA** (offline-first, устанавливается на телефон)
- **localStorage** (никаких серверов, никаких регистраций)
- **Без UI-библиотек** — всё на чистом CSS
- **79+ модулей**, JS ~230 KB (gzip ~74 KB)

git clone https://github.com/zimatoken/kapital-garden.git

# Установить зависимости

npm run dev
